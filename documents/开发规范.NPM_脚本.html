    NPM 脚本

    项目内置了一些 NPM 脚本，用于编译和打包项目。

    脚本列表

    由以下脚本可用：

    1. build：最终构建项目，生成可供发布的.mcaddon文件；
    2. ready：编译项目正常运行所需的脚本和语言文件，并将其部署到 Win32 平台中；
    3. clear：清除 Win32 平台中部署的项目；
    4. doc：生成项目开发文档；
    5. prettier：用 Prettier 来格式化项目中的所有文件。

    这些脚本可以帮助开发者自动化项目的构建、准备和格式化等任务。
