    游戏内容

    材料体系

    • 重新设计了材料体系
      • 加入了闪耀之石，挖掘荧石概率掉落
      • 加入了恐惧之石、恐惧之魂
      • 加入了古战残骸、远古碎片
      • 加入了魔晶材料、秘银材料、精炼岩材料
      • 现在原初合金（最高等级）具有了抗火功能
    • 为所有类型材料添加了对应盔甲
    • 允许所有盔甲进行纹饰操作
    • 加入了碎石机
    • 移除了仿制材料

    工具与武器

    • 重新设计了工具和武器
      • 移除了小刀、锥、锤

      • 加入了各种强化弓、强化箭

    • 加入了弓匠台
    • 现在使用锯、重锤等工具挖掘对应方块时有几率获得额外增产

    饰品

    • 加入了五种饰品槽和对应的饰品

    BOSS

    • 提高了所有 BOSS 的血量

    职业

    破坏性更改

    数据驱动

    • 使用原版的minecraft:geometry.full_block构建完整方块
    • 将配方、物品、方块文件的格式版本更新到 1.21.130 版本
    • 改进了挖掘与物品等级系统，现在使用纯原版数驱实现

    合成标签

    • 开放了alchemy_table合成标签，适用于炼金台；
    • 开放了bowyers_bench合成标签，适用于弓匠台。

    本地化

    • 使用 JSON 文件储存本地化字符串；
    • 标准化了所有本地化字符串的格式，以方便与高亮显示相关附加包兼容；
      • 需要注意的是，高亮显示相关附加包大多对原版 UI 进行了修改，因此一些可能的兼容性问题我们仍然无法修复。
    • 加入了英语、俄语、日语、繁体中文、文言文的翻译
      • 这些翻译还不完整，欢迎到 https://translate.codeberg.org/projects/hidden-years/ 贡献翻译

    打包

    • 启用了新的打包方式
      • 音乐与包图标文件被压缩以减小体积
      • 数据驱动文件均被压缩

    物品组件

    物品组件

    hiddenyears:hidden_effect_food

    • 添加自定义模拟效果
    • 支持破伤风、失血、脱水、干旱效果
    • 可配置持续时间和效果等级

    hiddenyears:effective_food

    • 添加状态效果
    • 支持效果分组（ALL/GOOD/BAD）
    • 可配置粒子效果和持续时间

    hiddenyears:custom_tool

    • 自定义工具类型
    • 支持镐、斧、剑、铲、锄等类型
    • 可设置为虚拟工具（无耐久消耗）

    hiddenyears:custom_weapon

    • 自定义武器系统
    • 支持虚拟武器模式
    • 无耐久消耗特性

    hiddenyears:tool_type

    • 设置工具类型
    • 支持锤子、撬棍、锯子等特殊工具
    • 影响方块交互行为

    hiddenyears:weapon_type

    • 设置武器类型
    • 支持剑、锤子、匕首等类型
    • 影响战斗行为

    hiddenyears:custom_crossbow

    • 自定义弩系统
    • 支持拉力等级配置
    • 可自定义弹药列表

    hiddenyears:arrow_present

    • 箭矢预设系统
    • 支持日光、雷光、烈焰、寒钢等类型
    • 特殊效果配置

    hiddenyears:trophy_bundle

    • 历战宝袋系统
    • 支持硬编码和脚本战利品表
    • 可配置战利品来源

    hiddenyears:exp_food

    • 食物经验值系统
    • 可自定义经验值数量

    hiddenyears:coin

    • 货币系统
    • 支持统一货币值
    • 可配置货币价值

    hiddenyears:staff

    • 范围法杖系统
    • 可配置伤害和范围
    • 支持粒子和音效效果

    hiddenyears:job

    • 职业系统
    • 支持行旅者职业
    • 可选择保留或移除旧职业

    hiddenyears:return_gem

    • 传送道具系统
    • 支持多种绑定方式
    • 可配置传送音效

    hiddenyears:specific_damage

    • 特定伤害系统
    • 可对不同生物族群设置额外伤害
    • 支持伤害范围配置

    hiddenyears:structure_placer

    • 结构放置系统
    • 支持高度限制
    • 可配置放置动画和偏移

    内部组件

    • hiddenyears:blessing_of_isis：雨神祝福
    • hiddenyears:complex_potion：复合药水
    • hiddenyears:adventurer_note：故地异国行纪
    • hiddenyears:profile：时匿怀表
    • hiddenyears:job_skill：职业技能

    方块组件

    hiddenyears:interactable

    • 标记方块为可交互方块

    hiddenyears:ore_type

    • 设置矿石类型（ruby/normal）
    • 影响挖掘行为

    hiddenyears:vault

    • 配置宝库功能
    • 支持战利品表、转换方块、钥匙和音效

    hiddenyears:boss_spawner

    • 设置BOSS祭坛
    • 支持BOSS ID、转换方块、钥匙
    • 可配置客户端事件和淡入淡出效果

    hiddenyears:trial_stone

    • 设置试炼之石
    • 支持三种状态：等待激活/激活/熄灭
    • 可配置战利品表、转换条件、钥匙和音效
