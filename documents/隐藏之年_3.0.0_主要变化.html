    游戏内容

    炼金台

    • 炼金台现在会发出等级为 8 的光；
    • 将徒手挖掘炼金台所需时间延长为 12 秒；

    魔法药水

    「故地异国行纪」

    • 加入了书籍「故地异国行纪」；
    • 开局自动获取，内容会随任务推进而持续更新；
    • 旨在引导玩家了解背景故事。

    命令

    • 添加了命令 /hiddenyears:credit，用于显示《隐藏之年²：天边的迦万涅尔》鸣谢名单。

    资源更新

    • 更新了项目的图标与 Logo；
    • 重新绘制了大部分纹理。

    修复

    • 修复了恶灵（现在被称为囚灵）运动轨迹不正常的漏洞

    技术性更新

    破坏性更新

    • 移除了 2.X 版本所有可用的物品标签；
    • 将附加包命名空间由hy改为hiddenyears

    数据驱动

    • 使用原版的minecraft:geometry.full_block构建完整方块；
    • 将配方、物品、方块文件的格式版本更新到 1.21.100 版本；

    合成标签

    • 开放了alchemy_table合成标签，适用于炼金台；
    • 开放了bowyers_bench合成标签，适用于弓匠台。

    本地化

    • 使用 JSON 文件储存本地化字符串；
    • 标准化了所有本地化字符串的格式，以方便与高亮显示相关附加包兼容；
      • 需要注意的是，高亮显示相关附加包大多对原版 UI 进行了修改，因此一些兼容性问题我们仍然无法修复。

    物品组件

    hiddenyears:adventurer_note

    • 开放了hiddenyears:adventurer_note物品组件：
    参数 类型 可选？ 描述
    N/A 使物品获得书籍「故地异国行纪」的功能

    例如：

    {
      "hiddenyears:adventurer_note": {}
    }

    hiddenyears:effective_food

    • 开放了hiddenyears:effective_food物品组件，可以为食物添加食用后的自定义状态效果：
    参数 类型 可选？ 描述
    effect string | string[] | EffectGroups 必填 食用后给予玩家的状态效果
    duration number | number[] 必填 状态效果持续的时间，以刻为单位，必须在范围[0, 20000000]内
    amplifier number | number[] 可选 状态效果等级
    show_particles boolean | boolean[] 可选 是否展示状态效果粒子
    clear string | string[] | EffectGroups 可选 要移除的状态效果类型

    在EffectGroups类型中：

    可用值 描述
    ALL 所有状态效果
    GOOD 正面状态效果
    BAD 负面状态效果

    hiddenyears:custom_tool

    • 开放了hiddenyears:custom_tool物品组件，可以将物品设置为自定义工具：
    参数 类型 可选？ 描述
    type ToolType 必填 工具的类型
    virtual boolean 可选 是否为虚拟工具，默认为false
    Important

    如果工具被设置为虚拟工具，则工具在挖掘方块时将不会消耗耐久度。

    在ToolType类型中：

    描述
    pickaxe 镐
    axe 斧
    sword 剑
    shovel 铲
    hoe 锄
    custom 自定义工具

    该可用值将会影响物品与方块交互时的行为。

    hiddenyears:trophy_bundle

    • 开放了hiddenyears:trophy_bundle物品组件，可以指定物品为历战宝袋：
    参数 类型 可选？ 描述
    loot_table string 可选 历战包袋的战利品表
    table_source TrophyBundleSourceType 必填 历战包袋的战利品表来源

    在TrophyBundleSourceType类型中：

    可用值 描述
    hardcode 硬编码
    script 脚本
    Important

    如果table_source参数为script，那么物品的最大堆叠必须为 1！

    其中的硬编码即指loot_table参数指定的战利品表，脚本指从物品的hiddenyears:loot_table动态属性获取战利品表。
