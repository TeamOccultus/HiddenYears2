# 隐藏之年 3.0.0 主要变化

## 游戏内容
### 炼金台
- 炼金台现在会发出等级为 8 的光；
- 将徒手挖掘炼金台所需时间延长为 12 秒；

### 魔法药水

### 「故地异国行纪」
- 加入了书籍「故地异国行纪」；
- 开局自动获取，内容会随任务推进而持续更新；
- 旨在引导玩家了解背景故事。

## 技术性

- 开放了以下合成标签：

```
alchemy_table
```

- 开放了以下物品组件：

```json
{
  "hiddenyears:adventurer_note": {}
}
```

将此组件添加到物品中，即可使其获得书籍「故地异国行纪」的功能。
